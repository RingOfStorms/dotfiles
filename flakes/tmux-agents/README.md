# tmux-agents

Agent awareness for a plain tmux setup, with no plugins inside the harnesses.

- **Navigator** (`prefix + w`, or tap the session badge / agent counts in the status bar): one heading per session, with individual panes nested directly below. Git sessions from the same project stay adjacent as `project - session [branch]`, with blue project names, purple session names, gray branches, and a gray project path only on the first heading. Each heading opens its first pane on Enter/click; pane rows open their own target. Pane labels include `session > window index:name > pane index:name`, so sessions are searchable on every row. Sessions spanning repos belong to the repo containing the most panes; ties use the first pane in tmux list order. Non-Git sessions have purple top-level headings. Grouping is recomputed every refresh; the list refreshes every second only when rows change, retaining the selected stable ID. Ctrl-J/K wraps; Ctrl-D/U pages down/up. Ctrl-X confirms `[y/N]` before killing the selected session or pane. Live previews move below the list on narrow terminals. fzf has no multi-column result list, so panes remain independently selectable in one column.
  Ctrl-C opens a session-name prompt: Enter creates, Esc cancels. The navigator reopens after either action; select the new session to switch to it. New sessions start in the selected pane's directory (the current pane's directory when the filter has no matches). Blank names create nothing; tmux rejects duplicates/invalid names without closing the navigator.
- **State**: a status-line `#()` tick (every `status-interval`, at most 2s) reads `#{pane_title}` for all panes and sets `@agent_state` (`working|idle|input`) per pane, `@agent_unseen` when an agent finishes or asks for input while you aren't looking at it, and `@agent_win` (`input|done`) per window. Unseen clears when you view the pane (selection hooks re-run the tick immediately).
- **Status**: segment prepended to `status-right` (`! n` needs input, `⠿ n` working, `● n` done unseen); non-current windows get a `!`/`●` marker in front of catppuccin's format.
- **Notifications** (when an agent finishes or needs input while you aren't looking): one master switch plus independent channels. `desktop` = notify-send on the tmux host; `message` = tmux message on every attached client (reaches ssh/mobile); `sound` = `off` | `local` (pw-play/paplay a file on the tmux host; separate done/needs-input sounds) | `bell` (terminal bell to each attached client, so an ssh/mobile client beeps or vibrates). Events in one tick are batched: one sound and one message.
- **Resume** (`resume.sh`, toggle with `resume.enable`): `$XDG_STATE_HOME/tmux-agents/resume.tsv` maps each agent pane to its omp session file. The tick saves agent changes and retries unresolved running agents until their session files exist; every tmux-resurrect save also updates the map. The pre-restore hook freezes map writes until resume workers finish, preventing partial pane creation and shell title resets from deleting mappings. After resurrect restores, each mapped pane gets `omp --resume=<file>`: run (`auto`) or only typed at the prompt (`prompt`), once the configured default shell replaces any pane-contents replay wrapper. Existing running agents are left alone. Resurrect must have saved the pane layout; the map alone cannot recreate panes added since its last save. Without resurrect, the file still identifies the sessions each pane was running.

## Detection

Agent state comes only from the terminal title, so sandbox wrappers like `nono run ... -- omp` work unchanged. For resume, the session file is taken from the JSONL the pane's `omp` process holds open (found by walking the pane's process tree), falling back to omp's per-terminal breadcrumb (`~/.omp/agent/terminal-sessions/pts-N`) for the agent's own tty. The pane tty's breadcrumb is not used: wrappers can give omp a separate pty, leaving an unrelated session at the pane tty. Resume is typed into the interactive shell, so the `omp` alias (and its wrapper) is what relaunches the session.

omp titles itself `π <spinner> label` while working, `π > label` when idle and `π ! label` when blocked on an ask/approval prompt. Titles that don't start with `π` aren't agents. To add another harness, extend `classify` in `tmux-agents.sh`.

## Options

Home Manager: import `homeManagerModules.defaultEnabled` (on by default) or `homeManagerModules.default` (set `enable` yourself). Options: `ringofstorms.tmuxAgents.{enable,key}`, `ringofstorms.tmuxAgents.resume.{enable,mode}` and `ringofstorms.tmuxAgents.notifications.{enable,desktop,message,sound,soundDone,soundInput,doneVolume,inputVolume}`. Resume hooks are registered at the beginning of tmux.conf, before continuum can start an automatic restore. The status/theme loader remains after catppuccin/resurrect/continuum via `lib.mkAfter`. For a manual installation, run `bin/tmux-agents resume-init` before loading continuum, then load `tmux_agents.tmux` after the theme.

tmux options: `@tmux-agents-key` (`w`), `@tmux-agents-mouse` (`on`: status-left and agent-count taps open the navigator, replacing the default status-left click), `@tmux-agents-notify` (`on`, master), `@tmux-agents-notify-desktop` (`on`), `@tmux-agents-notify-message` (`off`), `@tmux-agents-notify-sound` (`local`; `off|local|bell`), `@tmux-agents-sound-done` / `@tmux-agents-sound-input` (file paths), `@tmux-agents-sound-done-volume` / `@tmux-agents-sound-input-volume` (`15` / `90`, percent), `@tmux-agents-resume` (`on`), `@tmux-agents-resume-mode` (`auto`; `auto|prompt`), `@tmux-agents-resume-command` (`omp --resume=`), `@tmux-agents-interval` (`2`), `@tmux-agents-navigator-interval` (`1`), `@tmux-agents-popup-width`/`-height` (`85%`/`75%`). All are read at event time, so `tmux set -g @tmux-agents-notify off` takes effect immediately.

CLI (`bin/tmux-agents` in the plugin dir): `tick [quiet]`, `navigator`, `rows`, `preview TARGET`, `kill ID ROWS`, `create TARGET ROWS`, `save`, `restore`, `restore-begin` (pre-restore write freeze), `resume-init` (adds or removes the resurrect hooks per `@tmux-agents-resume`).
